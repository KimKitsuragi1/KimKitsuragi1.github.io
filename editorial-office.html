Automated Editorial Desk

自动编辑部

A semi-automated editorial workflow for Revachol Review.

工作流

1Submit

作者通过 GitHub Issue 表单投稿。

2Agent Review

GitHub Actions 调用编辑 Agent 自动初审。

3Editor Decision

金·曷城根据报告作出编辑决定。

4Publish

录用稿件制作网页、PDF，并上传 Zenodo 生成 DOI。

标签体系

Label用途
submission投稿入口。
pending-review等待自动审稿。
agent-reviewedAgent 已生成报告。
fact-check-needed需要事实核验。
legal-risk存在法律或诽谤风险。
revise需要修改。
accepted录用。
published已经发布。

原则

Agent 只做初审，不替代主编判断；自动化只管理文本流程，不决定文章真理。

本系统尤其关注事实来源、法律风险、性别化表达、被害人中心原则和风格一致性。
