投稿类型

栏目建议长度说明
Articles / 论文8,000–20,000 字完整理论文章、开放工作论文。
Essays / 评论3,000–8,000 字公共议题评论、文化批判、媒介分析。
Case Notes / 案例札记2,000–6,000 字围绕案件、判决、宣传文本或舆论样本的短评。
Thought Cabinet / 思维阁形式开放允许《极乐迪斯科》式多声部讨论，但必须保留论证结构。

投稿流程

  1. 点击上方 Open GitHub Submission Form。
  2. 按表单填写作者、题目、摘要、栏目、正文和来源。
  3. 可选：使用自己的 ChatGPT 账号运行 Review GPT 或下载审稿 Prompt 完成自审。
  4. 将自审报告与稿件一起提交，主编手动作出 Accept / Revise / Reject。
  5. 录用稿件会进入网页制作、Zenodo DOI、版本发布流程。

投稿前检查

  • 具体案件必须标注来源：判决书、官方通报、权威报道或网络争议样本。
  • 不要把未经核验的网传材料当作事实。
  • 避免性别、地域、职业等群体本质化攻击。
  • 可以锋利批判，但要把结论写成结构分析、文本分析或制度分析。
  • 被害人位置不能被加害者悔悟故事覆盖。
